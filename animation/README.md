# Tavern animation system — provisional

Status ceiling: `render-candidate`. Nothing here is production-ready, approved, scheduled, uploaded or published. Every premise is synthetic fiction; Issue #8 collection remains disabled.

## Style and delivery

Use reusable 2D cutout layers, strong expressions, limited movement, fast readable cuts, caption-led jokes, and simple 9:16 framing. Masters target 1080×1920 and generally 15–45 seconds. Story meaning must survive muted playback. No flashing, protected game media, private alliance details or insider-only punchline.

At a 360×640 review size, captions use at most two lines, semantic line breaks, a high-contrast solid backing, and enough display time for a mobile reader. Keep essential action/text in the conservative central region; Issue #9 must verify current platform overlays before export.

`fictional premise or approved minimized #8 brief → privacy screen → scored premise → script → IP/privacy review → storyboard → asset/shot manifest → animatic → caption/muted QA → technical render → rights audit → Sentinel → founder review → #9 handoff`

Allowed statuses: `premise`, `script`, `storyboard`, `render-candidate`, `founder-review`, `approved`, `scheduled`, `published`, `withdrawn`, `rejected`, `archived`. This package must not exceed `render-candidate` without external gates.

# Asset rights register

This is the canonical rights inventory. Create one row per asset before it is added to `public/`, merchandise, animation, social content, or production design files. Keep private purchase receipts or license files in an approved restricted location and link only a non-sensitive evidence reference here.

| Rights ID | Asset / path | Type | Creator / source | License and version | Commercial use allowed | Modification allowed | Attribution required / text | Evidence reference | Protected-reference and similarity review | Reviewer / date | Status |
|---|---|---|---|---|---|---|---|---|---|---|---|
| EXAMPLE-ONLY | Delete this example when the first real entry is added. | font / icon / texture / image / audio / video / generated | URL, vendor, or named creator | Exact terms and access date | yes/no/unclear | yes/no/unclear | Exact required credit or none | Non-secret receipt/license reference | Reviewer confirms prompt/source did not reference protected work and output is not confusingly similar | Name / ISO date | blocked/cleared/retired |

## Rules

- `cleared` requires commercial-use scope, evidence, required attribution, and human review.
- `unclear`, missing evidence, or unresolved similarity means `blocked`.
- Generated assets record the tool/model, generation date, prompt reference, material edits, and human reviewer; prompts may not reference protected games, artists, characters, franchises, screenshots, or assets.
- Retired or expired assets stay in the register so prior usage remains auditable.
